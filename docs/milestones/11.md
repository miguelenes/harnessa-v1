## Scope and implementation

Baseline: `origin/main` at `233678767bed6dde7deb10b30eb547c0509dfd31`. This change adds the version 2 typed core evidence envelope, a project-authorized provenance projection API, generated TypeScript types, a task inspector tab with task/run/source/revision filters and cursor pagination, a minimized Harness² fixture contract, a bounded artifact checksum reconciliation action, and durable late gateway usage reconciliation. Source rows remain authoritative; usage corrections append new ledger events. See `docs/integrations/evidence-plane.md` for the source matrix, contracts, retention and backup guidance.

The API omits prompt/completion content, raw webhook JSON, tool arguments/results, and artifact bytes. Gateway billed spend, estimated spend, and unknown usage are labeled separately; provider-reported spend remains unknown unless supplied by a source. Failed webhook receipts are marked retryable and artifact bytes remain `checksum_unverified` until a member runs the integrity check. The integrity action reads at most 64 MiB, writes no external effect, and appends a deduplicated domain audit event for a repeated identical result. Late spend observations use a bounded batch, durable source-observation IDs, retryable/ambiguous states and append-only `usage_reconciled` ledger events. The additive migration is `8c7e2d1f4a90`.
