## Scope and implementation

Baseline: `origin/main` at `233678767bed6dde7deb10b30eb547c0509dfd31`. This change adds the version 2 typed core evidence envelope, a project-authorized provenance projection API, generated TypeScript types, a task inspector tab with task/run/source/revision filters and cursor pagination, a minimized Harness² fixture contract, a bounded artifact checksum reconciliation action, and durable late gateway usage reconciliation. Source rows remain authoritative; usage corrections append new ledger events. See `docs/integrations/evidence-plane.md` for the source matrix, contracts, retention and backup guidance.

The API omits prompt/completion content, raw webhook JSON, tool arguments/results, and artifact bytes. Gateway billed spend, estimated spend, and unknown usage are labeled separately; provider-reported spend remains unknown unless supplied by a source. Failed webhook receipts are marked retryable and artifact bytes remain `checksum_unverified` until a member runs the integrity check. The integrity action reads at most 64 MiB, writes no external effect, and appends a deduplicated domain audit event for a repeated identical result. Late gateway usage reports are operator/admin-only, explicitly labeled as unverified submissions, and use durable source-observation IDs, bounded retries (12 attempts), and append-only `usage_reconciled` ledger events protected against concurrent duplicates. A worker retries due receipts every 30 seconds in batches of at most 100. The additive migration is `8c7e2d1f4a90`.

## Migration, rollback, and external setup

Migration `8c7e2d1f4a90` adds the usage import receipt table, provider-reported spend column, and `usage_reconciled` ledger event type. Its downgrade keeps the ledger check constraint compatible with already-persisted `usage_reconciled` events while removing the new receipt table and observation/provider columns. The downgrade/upgrade cycle is verified against disposable PostgreSQL 16.13, including after a persisted correction event. For rollback, stop usage import writers, export or retain gateway import receipts, then run `uv run alembic downgrade -1` before reverting code; this removes import receipts. Artifact integrity checks are read-only apart from their domain audit event. Live provider setup is not required for the deterministic fixture path; no real provider credential, GitHub App, or paid request was used. No secrets were added to this report.
