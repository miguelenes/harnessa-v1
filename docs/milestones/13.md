## Implementation delivered so far

- Task board now supports local search, stage filtering, and cursor-based loading of older task rows.
- OpenSpec explorer now has search, section filtering, incremental display, and safe GitHub revision links when repository target and full commit SHA are available.
- Evaluation center projects task readiness and project-authorized immutable Harness² experiment context, distinguishes blocked/unavailable external benchmarks, and does not fabricate scores.
- Setup & health checklist reports administrator, repository-grant, model-route, GitHub installation, and runtime status. Route verification is an explicit one-token action guarded by administrator identity, a checkbox, and the selected project's existing budget controls; its default state makes no provider request.
- API request records are structured JSON with validated request/trace correlation IDs; protected metrics include process-local HTTP counters/histograms and five-second cached, aggregate database gauges for queue/lease/dead-letter/outbox/effect/spend/artifact/GitHub/cleanup/route-candidate state. Collection failures are explicit and redacted, and metric labels omit tenant identifiers.
- Next.js and Astro receive native SVG favicon/app-icon assets. A generated editorial workflow illustration with recorded prompt provenance is integrated into the marketing hero and README.
- Compose persists shared API/worker artifacts in a named volume and adds restart, grace-period, and resource controls.
- Operator, recovery, and acceptance guides document bootstrap, readiness, backup/restore, secrets, and current boundaries.
- Restore now checks the artifact volume before restoring the database, avoiding a database-only partial restore when the target volume is occupied.
