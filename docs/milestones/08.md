### AG-UI compatibility boundary

AG-UI is a UI event protocol and client package; it is not the durable event store or replay authority. The server encodes official Python event models. The browser consumes the official `@ag-ui/core` event union and uses `@ag-ui/client`'s `isRecognizedEvent` guard. Harnessa retains durable ordering, authorization, cursor retention, idempotency, scheduling, and recovery.

The resume envelope is `GET /projects/{project_id}/events/stream?after=<project_sequence>` with `Accept: text/event-stream`. Each persisted frame has `id: <project_sequence>` and one standard encoded AG-UI event as its `data:` value. The browser stores the last accepted project sequence in tab-scoped `sessionStorage`; `retry: 3000` is server advice. On `410 event_cursor_expired`, the client reloads authorized task snapshots, sets the supplied oldest-available boundary, and reconnects. Closing the HTTP reader only releases the subscription. The explicit authenticated cancel command is separate.

Python protocol dependency: `ag-ui-protocol` 1.0.0. Browser protocol packages: `@ag-ui/core` and `@ag-ui/client` 1.0.3. The installed versions are pinned in `pyproject.toml`/`uv.lock` and `apps/web/package.json`/`pnpm-lock.yaml`. Implementation was checked against the official [Python event models](https://github.com/ag-ui-protocol/ag-ui/blob/main/sdks/python/ag_ui/_generated/models.py), [Python EventEncoder guide](https://github.com/ag-ui-protocol/ag-ui/blob/main/docs/sdk/python/encoder/overview.mdx), and [TypeScript event types](https://github.com/ag-ui-protocol/ag-ui/blob/main/docs/sdk/js/core/events.mdx). Local typecheck/tests confirm the locked SDK APIs. The encoder emits standard JSON SSE event data; durable project sequence IDs and replay are Harnessa's envelope and authority. Durable ACP updates are written as new `DomainEvent` rows using the existing project sequence, fenced run lease, and run/task state checks. Each message is buffered to 8192 characters and the UI event collector is capped at 512 records per ACP session. The shared credential-pattern filter is best-effort screening, not a general secret detector; tool arguments and results remain omitted. Message content is emitted when the ACP message completes, rather than token-by-token. AG-UI still does not provide durable replay.
