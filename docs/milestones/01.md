# Milestone 1 — Foundation, contracts, and access control

**Status: implemented and locally verified.** This milestone stops before agent execution and the rest of the product views.

## Delivered

- Modular Python/Node monorepo with `apps/web`, `apps/api`, `packages/contracts`, `infra`, `tests`, and `docs`.
- Python 3.12 / uv API with FastAPI, Pydantic v2, async SQLAlchemy, Alembic, PostgreSQL 16, and Redis.
- Next.js 16 App Router UI with sign-in, project list/create, repository registration, Tailwind v4, and shadcn/ui component conventions.
- Pydantic task stages, independent run status, task state, event, error, identity, authorization context, specification revision, artifact metadata, project, and repository schemas. Domain code guards lifecycle transitions and optimistic versions. All canonical server schemas are published in OpenAPI and TypeScript types are generated from that document; the web app consumes generated project/repository types.
- Initial migration for organizations, users, memberships, projects, project memberships, repositories, tasks, and idempotency records. Task records reserve branch return stage and keep lifecycle stage independent from run status. Migration history is recorded by Alembic and organizations carry a schema version.
- FastAPI Users cookie authentication, one-time administrator bootstrap, 12-character password floor, organization and project authorization, HttpOnly cookie, SameSite=Lax, production Secure-cookie requirement, double-submit CSRF on login and mutations, exact Origin allowlist, and transactionally idempotent project/repository POSTs.
- A shared project authorization service scopes repository operations and project discovery to local organization/project memberships. Milestone 1 has no task or artifact HTTP endpoints or artifact storage; those resources remain inaccessible until their later API surfaces are implemented with this same project-scope check.
- Repository registration is restricted to exact administrator-configured target IDs. No GitHub authorization, repository fetch, clone, or scan occurs.
- Podman Compose services, health/readiness endpoints, `.env.example`, and startup instructions.
