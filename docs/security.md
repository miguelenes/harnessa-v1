# Security

See the repository's [security policy](https://github.com/miguelenes/harnessa-v1/blob/main/SECURITY.md) for supported versions and private vulnerability reporting.

Harnessa is under active development. Do not use the preview portal to submit credentials or sensitive data. For local deployments, keep `.env` private, use unique secrets, expose only intended services, and scope repository access through the explicit allowlist.
