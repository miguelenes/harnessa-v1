# Contributing

Thanks for helping improve Harnessa. Read the repository's [contribution guide](https://github.com/miguelenes/harnessa-v1/blob/main/CONTRIBUTING.md) for scope, development commands, review expectations, and the required local secret-scanning hook. The [security policy](security.md) explains how to report vulnerabilities privately.

## Where to ask

- Use [GitHub Discussions](https://github.com/miguelenes/harnessa-v1/discussions) for questions and design proposals.
- Use [Issues](https://github.com/miguelenes/harnessa-v1/issues/new/choose) for reproducible bugs and actionable feature requests.
- Open a [pull request](https://github.com/miguelenes/harnessa-v1/compare) when a change is ready for review.

Please do not include credentials, private customer data, or unpublished security details in public discussions or issues.
