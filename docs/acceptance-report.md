## External evaluation decision

The initial candidate, [AgentSWE-Lite](https://github.com/VectorSpaceLab/AgentSWE), was rejected for hidden-holdout use. Its eight published tasks are public, builders have network access, and its Editing tasks call DeepSeek directly rather than Harnessa's budget ledger.

The preferred independent evaluator is **Harbor 0.24.0 running Scale's SWE-bench Pro V2 public split**, pinned to upstream task tree commit `66f92766bba642462d4bbe5479e83f91f9211862`. The public split has 642 tasks across 11 repositories. Its locked protocol restricts the agent phase to the model endpoint, disables web tools, and re-grades each diff on a pristine image. This is an evaluator setup recommendation and smoke-tested local harness; it is **not yet integrated with Harnessa's global spend ledger**, so model runs must not be started through Harbor directly. Any Harnessa-backed agent adapter must route all model requests through Harnessa before this can be used for paid acceptance. [Official SWE-bench Pro V2 protocol and split description](https://labs.scale.com/leaderboard/swe_bench_pro_public_v2), [Harbor 0.24.0 release](https://github.com/harbor-framework/harbor/releases/tag/v0.24.0).

The public tasks are hidden from the evaluated agent when the locked protocol is followed, but the dataset, task definitions, trajectories, and grader materials are publicly accessible. This is **agent-hidden evaluation, not a confidential holdout**. Scale's separate private subset is proprietary partner data. Scale's public materials do not give an external account workflow, endpoint, or submission process for that private subset; access remains owned by Scale's benchmark team and is unavailable to this project. Do not represent public results as confidential holdout results.

For an evaluator that can be self-hosted without Scale access, **SWE-bench-Live (Python) is the practical protocol-isolated alternative**. Its public Hugging Face dataset card lists an MIT license and a test split of about 1,000 tasks, and Microsoft's official repository provides the evaluation harness. The protocol requires the agent to receive only the `problem_statement` and task Docker image; it must not receive dataset hints, `FAIL_TO_PASS`, `test_patch`, or other answer-bearing fields. Because those fields and patches are public in the dataset, this is **not a confidential or globally secret holdout**. Keep the dataset and grader outside the agent boundary, freeze the dataset revision and authorized task IDs in Harnessa's immutable manifest, and give the agent only the statement and sandbox. This alternative can provide independently graded development/acceptance evidence; it does not grant Scale's stricter holdout access. No dataset has been downloaded, no adapter has been installed, and no benchmark score is claimed. [Official SWE-bench-Live protocol and runner](https://github.com/microsoft/SWE-bench-Live/blob/main/README.md), [dataset license and split metadata](https://huggingface.co/datasets/SWE-bench-Live/SWE-bench-Live).

The hosted SWE-bench Multimodal `test` service is a real option for independently graded hidden-test evaluation, but it is **not currently a usable Harnessa acceptance path**. The official SWE-bench evaluation guide says Multimodal `test` evaluation is available only through `sb-cli`; the `sb-cli` README's general split list is inconsistent with its dedicated Multimodal submission instructions, which provide the `swe-bench-m test` command. Those instructions require an API key obtained through an email verification flow and describe limited test quota; the related mini-SWE-agent guide describes cloud evaluation as free, while the quota documentation says available runs depend on subscription level. The docs show how to submit predictions and retrieve reports, but I found no documented route for obtaining hidden test task statements and IDs for Harnessa to solve. Harnessa's task-creation contract accepts title and description but has no image/attachment field, and current model compatibility documentation lists no tested vision route. Revisit only if the benchmark maintainers provide an authorized task feed compatible with Harnessa and a verified vision route is configured. No email was sent, account or API key was created, quota was checked, prediction was submitted, or public leaderboard PR opened. [Official SWE-bench evaluation guide](https://github.com/SWE-bench/SWE-bench/blob/main/docs/assets/evaluation.md), [`sb-cli` README](https://github.com/swe-bench/sb-cli), [Multimodal submission guide](https://www.swebench.com/sb-cli/submit-to-leaderboard/), [quota docs](https://www.swebench.com/sb-cli/user-guide/get-quotas/), [cloud evaluation and pricing statement](https://github.com/SWE-agent/mini-swe-agent/blob/main/docs/usage/swebench.md).

M13's implemented local evaluator is the Harnessa-owned Harness² suite: it creates immutable grouped manifests, freezes task/spec/base/policy and route revisions, estimates bounded cost, runs matched baseline/candidate/composed experiments, and summarizes rollouts. It is not an independent evaluator. A private Harnessa-authored synthetic suite would not be independent and is not represented as a hidden benchmark. Scale's official materials describe a private held-out OSS set and a separate commercial set from proprietary partner repositories; the public materials reviewed do not provide an external application, account, endpoint, or task-submission path for either set. Until Scale grants an account/endpoint and authorized task access, confidential/held-out results remain unavailable. This is an external access blocker, not evidence that no such route can be granted privately. [Scale SWE-Bench Pro V2](https://labs.scale.com/leaderboard/swe_bench_pro_public_v2), [Scale benchmark paper](https://labs.scale.com/papers/swe_bench_pro), [paper PDF](https://static.scale.com/uploads/654197dc94d34f66c0f5184e/SWEAP_Eval_Scale%20%289%29.pdf).

[Official runner](https://github.com/Job-Bench/job-bench-eval), [dataset card](https://huggingface.co/datasets/JobBench/job-bench)

- **SWE-bench-Live:** an additional MIT-licensed public dataset with an official self-hosted evaluator and a protocol that isolates answer-bearing fields from the evaluated agent. It is recommended as a reachable protocol-isolated option, not described as a confidential holdout; no Harnessa adapter or task run is present. [Official evaluator protocol](https://github.com/microsoft/SWE-bench-Live/blob/main/README.md), [dataset card](https://huggingface.co/datasets/SWE-bench-Live/SWE-bench-Live)
