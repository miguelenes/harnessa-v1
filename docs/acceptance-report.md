## External evaluation decision

The selected candidate for an independently authored software-agent benchmark is [AgentSWE-Lite](https://github.com/VectorSpaceLab/AgentSWE). Its eight published tasks are `repo`, `db`, `pdf`, `deeptutor`, `aider`, `openwiki`, `tau3`, and `pinch`; its paper reports three runs per task and uses DeepSeek-V4.1-Flash for runtime and judge. The upstream repository is Apache-2.0, while its reused task assets retain their own licenses and require a per-task audit before redistribution or execution.

AgentSWE-Lite does **not** meet Harnessa's hidden-holdout requirement by itself: upstream says held-out cases ship in the public repository and builders have network access. Its Editing tasks also send builder/runtime/judge requests directly to DeepSeek, bypassing Harnessa's budget ledger. Therefore the suite is a research selection, not a configured or accepted evaluator endpoint, and no task has been downloaded or run. A trusted M12-style holdout still needs a separately permissioned evaluator service and an operator-controlled private dataset; those are not provisioned in this checkout. [AgentSWE benchmark and task details](https://github.com/VectorSpaceLab/AgentSWE/blob/main/README.md), [upstream model-routing and key boundaries](https://github.com/VectorSpaceLab/AgentSWE/blob/main/docs/ENV.providers.md), [upstream host/runtime requirements](https://github.com/VectorSpaceLab/AgentSWE/blob/main/docs/ENV.md).

## Benchmark licensing and availability

- **WorkBuddy-Bench:** Tencent's repository license says the benchmark is not intended for use within the European Union. Harnessa does not download or execute it pending documented jurisdiction/license review. This is a blocked adapter, not a zero score. [License](https://github.com/Tencent/workbuddy-bench/blob/main/LICENSE)
- **JobBench:** the official runner supports CLI/Harbor workflows and uses an external LLM judge (documented default: xAI Grok). Although the official eval code declares Apache-2.0 and the Hugging Face dataset page declares MIT, direct runner/judge execution is not integrated with Harnessa's model budget ledger, cancellation, isolated runner, immutable evidence manifests or evaluation UI. [Official runner](https://github.com/Job-Bench/job-bench-eval), [dataset card](https://huggingface.co/datasets/JobBench/job-bench)
- **Harvey LAB:** the official GitHub repository declares MIT and includes a task set and its own execution/evaluation harness. No Harnessa adapter or metered judge integration is installed. [Official repository](https://github.com/HarveyAI/harvey-labs)

No benchmark package or dataset has been downloaded into this repository. The two model-backed calls above were configuration checks only; no benchmark run was started.
